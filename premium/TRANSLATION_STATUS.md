## 번역 지침

### 번역 대상

| 타입 | 설명 | 번역 여부 |
|------|------|----------|
| dlg | NPC/PC 대화 | 전부 번역 |
| utc | 크리처 이름 (FirstName) | 전부 번역 |
| uti | 아이템 이름/설명 (LocalizedName, DescIdentified) | 번역 (내부 템플릿명 제외) |
| utp | 배치물 이름/설명 | 전부 번역 |
| utd | 문 이름/설명 | 전부 번역 |
| utm | 상점 이름 | 전부 번역 |
| utt | 트리거 이름 | 전부 번역 |
| ute | 인카운터 이름 | 전부 번역 |
| uts | 사운드 이름 | 전부 번역 |
| jrl | 저널/퀘스트 | 전부 번역 |
| git | GIT 크리처/배치물/문 인스턴스 이름 | 전부 번역 |
| ifo | 모듈 이름/설명 (Mod_Name, Mod_Description) | 전부 번역 |

- **StrRef가 있어도 인라인 텍스트가 있으면 번역 필요** — 엔진이 인라인 텍스트를 우선 사용
- 내부 템플릿명(`bishop_b`, `knight_b` 등 코드명)만 스킵

### 기존 번역 참조

- **dialog.tlk 번역**: StrRef가 있는 항목은 `translate/dialog_translated/` CSV에서 해당 StrRef 검색하여 동일 번역 사용
- **용어 통일**: `CLAUDE.md` 및 메모리의 번역 용어 통일 기록 참조
- **NWN 토큰**: `<FirstName>`, `<FullName>`, `<lad/lass>` 등은 엔진 토큰으로 원문 그대로 보존

## 빌드 명령

```bash
python3 premium/extract_module.py --all              # 전체 추출
python3 premium/extract_module.py --all --preserve    # 기존 번역 보존하며 재추출
python3 premium/build_premium.py chess --release      # 단일 모듈 빌드
python3 premium/build_premium.py --all --release      # 전체 모듈 빌드
```
